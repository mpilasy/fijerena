## 2025-02-23 - [BroadcastReceiver Export Vulnerability]
**Vulnerability:** A debug broadcast receiver (`EpgSyncDebugReceiver`) was marked with `android:exported="true"` without permission constraints in `tv/src/main/AndroidManifest.xml`. This allowed any third-party app installed on the device to send the `org.njarasoa.fijerena.DEBUG_EPG_SYNC` intent and trigger the WorkManager's `EpgSyncWorker` forcefully, potentially leading to unauthorized data usage, battery drain, or denial of service by overwhelming the EPG synchronization pipeline.
**Learning:** Receivers, especially those meant solely for internal debugging or system components, should strictly restrict access. Without an intent-filter or if `exported` is strictly set to false, unauthorized external access is prevented. If external access is required (e.g., from an ADB shell without root), alternative mechanisms or custom permissions should be employed rather than unconditionally exporting the receiver.
**Prevention:** Ensure `android:exported="false"` is set for debug receivers, or protect them with a custom signature-level permission so that only apps signed with the same key can trigger them.
